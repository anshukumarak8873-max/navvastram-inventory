NAVVASTRAM INVENTORY V2
Upload these four files to the existing GitHub repository, replacing the old versions.
Features: item add/edit, camera barcode scan/assignment, duplicate barcode prevention, stock inward, customer return, test sale stock deduction, movement history, low-stock count, stock valuation at current purchase price, estimated gross profit on test sales, JSON backup/restore, share backup file (choose Google Drive from Android share sheet).
Important: Stock value = current quantity x current purchase price. When purchase price is edited in inward entry, current price is updated for all remaining stock; this is a simple weighted-cost-free valuation model. If you need batch-wise FIFO/weighted average costing, that is a later enhancement.
Google Drive share is user-initiated, not automatic background sync. Data remains in this browser's local storage; backup regularly.
