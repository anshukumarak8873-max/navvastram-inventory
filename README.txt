V11 additions:
- 80mm / 3-inch receipt print layout for each saved bill.
- Print / PDF button on every bill in Bill History. In Android print preview choose "Save as PDF" to save the invoice.
- WhatsApp button shares the invoice details as a formatted message.
- Month filter for bill history, plus Show All Bills.
- Reprint / PDF any saved bill from history.
- Khata invoice includes Previous Balance, Current Bill, Amount Received, and Remaining Balance.

Important:
- The WhatsApp button shares bill details as text. To send the actual PDF, first use Print / PDF > Save as PDF, then share the saved PDF from Android Files/Downloads using WhatsApp.
- This browser-only app cannot silently create a monthly folder in phone storage. Choose/create the month folder when saving the PDF.
- Back up app data before updating. Do not clear browser/site storage.
- Existing localStorage key is preserved to retain existing app data.
