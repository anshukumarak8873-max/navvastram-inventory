NavVastram Inventory V11 - Thermal Print, PDF and Monthly Bill History

Included: 80mm (3-inch) receipt print layout; Print dialog can select a compatible thermal printer or Save as PDF; month-wise bill history; WhatsApp bill text sharing; previous bill history and khata settlement details retained.

IMPORTANT: Back up your data before updating. Upload and replace index.html, manifest.json, sw.js and README.txt in the ROOT of your existing GitHub Pages repository. Keep the same URL and do not clear browser site data. Existing localStorage key is preserved.

PDF saving: In Android Chrome print preview, choose Save as PDF and select the folder. Automatic monthly folder creation is not supported by the browser; select/create the month folder manually when saving. Thermal printing depends on the printer supporting browser print output / compatible print service.
